# V040: Tree-sitter Node accessor that breaks on the language-pack 1.8.1 floor

## Overview

Dogfooding rule that checks reveal's own `reveal/` and `tests/` for tree-sitter Node
reads that pass on every runner with a recent tree-sitter-language-pack and fail only on
CI's compat leg pinned to the 1.8.1 floor. There `node.start_byte` is a bound METHOD
(the vendored `builtins.Node`), from 1.12.5 on a property (BACK-1406: a test helper's
`data[node.start_byte:node.end_byte]` reached CI red after a green local run).

It is `scripts/check_treesitter_accessors.py` moved into `reveal reveal:// --check`
(BACK-1707): same patterns, same suppression, same findings; the script and its CI and
ci-local steps are gone. Strict, not baselined.

Only fires via `reveal reveal:// --check` (self-check of the dev checkout); it
does not run against user code.

## Rule Details

- **Code**: V040
- **Category**: validation
- **Severity**: MEDIUM
- **File Patterns**: `reveal://` self-check only (`internal = True`)

Flagged:

- a read of `.start_byte`, `.end_byte`, `.start_point`, `.end_point`, `.child_count`,
  `.has_error`, `.is_missing`, `.to_sexp` (not writes, not `mock.<name>.return_value` /
  `.side_effect`); read it with `reveal.core.treesitter_compat._zero_arg(node, 'start_byte')`;
- `.field_name_for_child` / `.field_name_for_named_child` (absent on the floor); use
  `child_by_field_name(...)` per field and compare spans (BACK-1700);
- `.children` on a node (only in a file that mentions tree-sitter machinery, and only on
  a node-named receiver such as `node`, `child`, `n`, `root`, `*_node`, or a call that
  returns one); use `node_children(node)`;
- `==` / `!=` between two node-named operands; the floor's Node compares by identity, so
  compare `(_zero_arg(n, 'start_byte'), _zero_arg(n, 'end_byte'))` spans. `in` over a list of
  nodes is the same hazard and is not detected.

## Examples

### Bad (Triggers V040)

```python
text = data[node.start_byte:node.end_byte]
```

### Good (Passes V040)

```python
text = data[_zero_arg(node, 'start_byte'):_zero_arg(node, 'end_byte')]
```

## Suppression

`# noqa: ts-accessor` (the spelling the repo already used; the seam
`reveal/core/treesitter_compat.py` is its intended user) or `# noqa: V040` on any line of
the flagged expression.
