# V041: Text I/O without encoding= (Windows cp1252 ratchet)

## Overview

Dogfooding rule that checks reveal's own `reveal/`, `tests/` and `scripts/` for text-mode
file I/O with no explicit `encoding=`. On Windows the default text encoding is cp1252, so a
bare `Path.read_text()` / `open(p)` on a non-ASCII file raises `UnicodeDecodeError` there
while passing on Linux and macOS (BACK-1346/1347).

It is the check of `scripts/check_text_encoding.py` (BACK-1354) moved into
`reveal reveal:// --check` (BACK-1707): same call classification, same ratchet, same findings
(2151 legacy sites in 172 files, identical before and after the move). The script stays only as
the maintenance tool and shares V041's scan; CI and ci-local run the rule, not the script.

Only fires via `reveal reveal:// --check` (self-check of the dev checkout); it
does not run against user code.

## Rule Details

- **Code**: V041
- **Category**: validation
- **Severity**: MEDIUM
- **File Patterns**: `reveal://` self-check only (`internal = True`)

Flagged calls: `open` / `io.open` / `Path.open` / `read_text` / `write_text` in text mode;
`tempfile.NamedTemporaryFile`-family in text mode; `subprocess.run/Popen/check_output/call/
check_call` with `text=True`, `universal_newlines=True` or `errors=` and no `encoding=`.
`**kwargs` is trusted. Not checked: stdout/stderr (`reveal.main._setup_console`) and aliased
`open`.

Two classes:

- **STRICT** (never baselined): in `tests/`, a bare read/open whose path derives from
  `__file__` or an UPPERCASE module constant (repo sources, docs, fixtures). Every site is
  reported.
- **Ratchet**: all other sites are counted per file against
  `scripts/text_encoding_baseline.json`. A file at or under its baseline is quiet; a file above
  it, or absent from it, is reported at every bare site (a count cannot say which one is new).

## Examples

### Bad (Triggers V041)

```python
text = Path(path).read_text()
```

### Good (Passes V041)

```python
text = Path(path).read_text(encoding='utf-8')   # or errors='replace' for user files
```

## Baseline

The baseline may only fall. After fixing sites:

```bash
python scripts/check_text_encoding.py --update-baseline   # refuses while a STRICT site exists
python scripts/check_text_encoding.py -v                  # list every offender
```

## Suppression

`# noqa: text-encoding` (the spelling the repo already used) or `# noqa: V041` on the call line.

## Development

### Testing

```bash
pytest tests/test_text_encoding_rule_back1707.py -v
```

### Implementation Notes

- `scan_modules(modules)`, `regressions(found, baseline)` and `load_baseline(root)` are shared by
  the rule and the script, so they cannot disagree.
- A module that cannot be read or parsed is reported as an unavailable prerequisite instead of
  being skipped silently.
- Findings use posix display paths relative to the checkout root.
- Local repro of the failure class on Linux (ASCII locale):
  `PYTHONUTF8=0 PYTHONCOERCECLOCALE=0 LC_ALL=C pytest tests/<file>`.
