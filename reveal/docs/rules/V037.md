# V037: POSIX-only call in a test without a Windows guard

## Overview

Dogfooding rule that checks reveal's own `tests/` for calls and names that do not
exist or do not work on Windows, in a module with no Windows guard. The local gate
runs on Linux, where all of them work, so such a test passes locally and fails
only in the Windows CI job.

Only fires via `reveal reveal:// --check` (self-check of the dev checkout); it
does not run against user code.

## Rule Details

- **Code**: V037
- **Category**: validation
- **Severity**: MEDIUM
- **File Patterns**: `reveal://` self-check only (`internal = True`)

Flagged (Unix-only per the CPython docs):

- `os.fork`, `os.getuid`/`geteuid`/`getgid`, `os.setsid`, `os.killpg`, `os.mkfifo`,
  `os.chown`, `os.WNOHANG`, and similar `os` names;
- `signal.SIGKILL`, `SIGSTOP`, `SIGHUP`, `SIGUSR1`, `SIGALRM`, `signal.alarm`,
  `signal.setitimer`, and similar `signal` names (`SIGTERM`/`SIGINT` exist on
  Windows and are not flagged);
- `import fcntl`, `pwd`, `grp`, `termios`, `resource`, `pty`, `tty`, `syslog`, `posix`;
- real I/O on a hardcoded `/tmp`, `/proc/` or `/dev/` path: `open('/tmp/x')`,
  `Path('/tmp/x').write_text(...)`, `cwd='/tmp'`, `dir='/tmp'`, `os.chdir('/tmp')`.

## Examples

### ❌ Bad (Triggers V037)

```python
def test_workers_exit_when_parent_is_killed(tmp_path):
    proc = subprocess.Popen(...)
    os.kill(proc.pid, signal.SIGKILL)
```

### ✅ Good (Passes V037)

```python
pytestmark = pytest.mark.skipif(sys.platform == 'win32', reason='POSIX signals')

def test_workers_exit_when_parent_is_killed(tmp_path):
    proc = subprocess.Popen(...)
    os.kill(proc.pid, signal.SIGKILL)
```

## Guards recognised

Anywhere in the module: `sys.platform == 'win32'` (or `!=`, or
`sys.platform.startswith('win')`), `os.name == 'nt'`, `platform.system() == 'Windows'`,
`hasattr(os, ...)`/`hasattr(signal, ...)`, `pytest.importorskip(...)`.

### Implementation Notes

- AST-based: a POSIX path used only as a string (a fake root handed to a mocked
  function, an expected value) and POSIX calls inside string literals (a
  fixture's source, a subprocess driver) are not flagged. Path-literal
  assertions are V039's job.
- The guard is module-level: a guard on one test exempts the module.
- Suppress a reviewed site with `# noqa: V037 <why>` on the reported line.
